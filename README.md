# Wikibox Editor

Редактор и энциклопедия альтернативной истории в стиле русской Википедии.
Сайт статический: HTML, CSS и JS без сборки.

## Как устроено

- `index.html`, `css/site.css` — оформление по образцу ru.wikipedia (Vector 2022).
- `js/render.js` — вики-разметка, карточки, диаграмма парламента.
- `js/data.js` — шаблоны карточек (государство, деятель, партия, выборы, сражение и др.) и пример.
- `js/app.js` — страницы сайта, поиск, редактор, медиатека, импорт и экспорт.
- `js/mapdraw.js`, `js/maps.js` — карты: глобус (как в статье «Россия») и плоские карты мира, редактор границ государств и союзов.
- `data/geo/countries.json` — границы стран (Natural Earth, общественное достояние).
- `data/geo/prov/` — 12 749 провинций, по файлу на страну: регионы Natural Earth нарезаны на ячейки около 15 тыс. км² (диаграмма Вороного). Файл страны грузится, только когда её разбивают на провинции.
- `vendor/` — d3 7.9.0, d3-geo-projection 4.0.0, topojson-client 3.1.0, topojson-server 3.0.1 (ISC), polygon-clipping 0.15.7 (MIT).
- `data/geo/tpl/` — шаблоны границ по годам (1492, 1715, 1815, 1880, 1914, 1920, 1938, 1945, 1960): государства из [historical-basemaps](https://github.com/aourednik/historical-basemaps) (А. Уреднек, лицензия GPL-3.0), разложенные по нашим провинциям. Эти данные распространяются по GPL-3.0.
- Провинции можно передавать между государствами (`map.owner`), создавать новые государства (`map.states`); основа карты — `map.base` (пусто — современные границы, или год шаблона).
- Границы провинций можно менять в редакторе карт (разрезать, обвести новую провинцию, объединить); правки хранятся в карте (`map.pedit`).
- `js/import.js` — импорт статей из Википедии через её открытый API (карточка, текст, таблицы, сноски, категории; картинки — ссылками на Викисклад). У импортированной статьи внизу ставится ссылка на источник и лицензию CC BY-SA 4.0.
- `data/wiki.json` — опубликованные статьи. Их видят все посетители. Карты хранятся в нём как настройки и дорисовываются при открытии сайта.

## Как публиковать свои статьи

1. Редактируйте статьи прямо на сайте. Правки хранятся в вашем браузере.
2. Откройте «Файл проекта» и нажмите «Скачать wiki.json для публикации».
3. Замените этим файлом `data/wiki.json` в репозитории и отправьте изменения (`git commit`, `git push`).

## Локальный запуск

Откройте `index.html` в браузере. Если открыть файл напрямую, сайт не прочитает `data/wiki.json` и покажет встроенный пример. Чтобы видеть опубликованные статьи, запустите любой локальный сервер, например `npx serve .`.
