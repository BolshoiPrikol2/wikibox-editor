# Апокрифопедия

Энциклопедия альтернативной истории в стиле русской Википедии и встроенный редактор статей «Апокриф».
Сайт статический: HTML, CSS и JS без сборки.

## Как устроено

- `index.html`, `css/site.css` — оформление по образцу ru.wikipedia (Vector 2022).
- `js/render.js` — вики-разметка, карточки, диаграмма парламента.
- `js/data.js` — шаблоны карточек (государство, деятель, партия, выборы, сражение и др.) и пример.
- `js/app.js` — страницы сайта, поиск, редактор, медиатека, импорт и экспорт.
- `js/mapdraw.js`, `js/maps.js` — карты: глобус (как в статье «Россия») и плоские карты мира, редактор границ государств и союзов.
- `data/geo/` — границы стран и регионов (Natural Earth, общественное достояние; упрощены через mapshaper).
- `vendor/` — d3 7.9.0, d3-geo-projection 4.0.0, topojson-client 3.1.0 (лицензия ISC).
- `data/wiki.json` — опубликованные статьи. Их видят все посетители. Карты хранятся в нём как настройки и дорисовываются при открытии сайта.

## Как публиковать свои статьи

1. Редактируйте статьи прямо на сайте. Правки хранятся в вашем браузере.
2. Откройте «Файл проекта» и нажмите «Скачать wiki.json для публикации».
3. Замените этим файлом `data/wiki.json` в репозитории и отправьте изменения (`git commit`, `git push`).

## Локальный запуск

Откройте `index.html` в браузере. Если открыть файл напрямую, сайт не прочитает `data/wiki.json` и покажет встроенный пример. Чтобы видеть опубликованные статьи, запустите любой локальный сервер, например `npx serve .`.
